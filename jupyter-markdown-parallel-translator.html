Jupyter Markdown Parallel Translator

コードセルを区切りとしてMarkdownセルの塊を抽出し、Chrome Built-in AI Prompt APIで並列翻訳
並列数
ここに .ipynb をドロップ
Notebook JSONをブラウザ内で解析します。コードセルの中身は送信せず、Markdownセルだけを翻訳対象にします。
抽出ルール
1. セル順を維持して走査
2. 連続するMarkdownセルを1つの塊に結合
3. codeセルが現れたら翻訳塊を確定し、コード区切りとして記録
4. 翻訳後は元NotebookのMarkdownセルに按分して戻す

長い塊はモデル制限に当たりやすいため、必要に応じて右側の原文欄で分割・編集してください。
